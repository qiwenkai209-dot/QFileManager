# Q管理 (QFileManager)

一款基于 **Kotlin + Jetpack Compose (Material 3)** 构建的现代 Android 设备管理器与文件处理利器。

支持六大分类文件深度管理、内置开源 **LocalSend 协议**无损高速局域网互传、集成 **Mobile FFmpeg** 实现手机本地浏览器/视频 App 离线 **M3U8 缓存分片批量智能嗅探与秒级直出合成为 MP4**、支持全盘**软件与本机文件深度清理**、**重复文件秒级筛查与智能清理**，以及支持**进度条自由拖拽、无黑边铺满全屏和横竖屏旋转**的高级音视频播放器。

---

## 🌟 核心特性一览

### 1. 本机文件与软件深度清理 (Storage & App Cleaner)
- 🧹 **五大核心垃圾维度深度扫描**：
  - 💾 **应用与系统临时缓存**：自动识别全盘散落的 `.tmp`, `.temp`, `.chk`, `.bak`, `.old` 等临时垃圾文件；
  - 🖼️ **相册缩略图与图库缓存**：深度排查 `DCIM/.thumbnails` 与 `Pictures/.thumbnails`，清理海量缓存索引，立竿见影释放数 GB，不损坏相册原图；
  - 📝 **日志与崩溃转储文件**：扫描清理 `.log`, `.dmp`, `crashlog`, `logs` 等废弃运行堆栈与转储残留；
  - 📦 **废弃安装包残留**：智能检测存储中的 `.apk` 安装包，自动比对系统已安装软件列表，安全标出“已安装冗余包”；
  - 📁 **无用空文件夹**：递归扫描卸载应用后留下的空文件夹树，一键清空多余冗余路径。
- 📱 **已安装软件空间分析与直达清理**：
  - 全面列出手机已安装的所有第三方应用及系统更新，按占用体积降序排序；
  - 展示 App 高清图标、真实名称、包名、版本及安装包占用大小；
  - **一键直达系统清除缓存**：点击即可快速唤起系统应用详情设置页，支持用户一键清除应用缓存与管理存储空间。

### 2. M3U8 批量离线缓存嗅探与秒级转 MP4
针对手机浏览器（夸克、UC、QQ浏览器、Kiwi、Xunlei等）和视频播放器缓存的分散切片问题，提供全自动恢复解决方案：
- 🔍 **全盘深度嗅探**：
  - 自动递归扫描 `Download/`、`UCDownloads/`、`Quark/Download/`、`Android/data/` 等离线缓存目录。
  - 智能识别标准 `.m3u8` 清单文件。
  - **无清单容错识别**：针对某些 App 仅缓存了 `0.ts`, `1.ts`, `2.ts` ... 碎片无 m3u8 的情况，自动启动自然数字排序算法（Natural Order Numeric Sorting），动态生成标准虚拟播放清单。
- 📊 **转码实时进度与速率指示**：
  - 实时显示转码百分比（0%~100%）、平滑动态进度条以及当前处理速度（如 `18.5x`）。
- 🧹 **源文件自动清理选择**：
  - 支持勾选【转码成功后自动删除源文件 (清理 TS 切片及 M3U8)】，一键释放数 GB 冗余切片。
- ⚡ **FFmpeg Direct Stream Copy 极速直出**：
  - 采用 `-c copy -bsf:a aac_adtstoasc -movflags +faststart` 指令。
  - 无需耗时重编码，纯粹解封装合并，几秒钟即可完成大视频合并，画质音质 100% 无损。
- 📲 **系统相册无缝刷新**：
  - 合成后的 MP4 自动存入标准公共目录 `Movies/M3U8Converted/`，自动通知系统相册即刻可见。

### 3. 重复文件深度筛查与智能瘦身 (Duplicate Cleaner)
- 🚀 **三阶段极速精准比对算法**：
  - **Step 1 (大小粗筛)**：毫秒级分组过滤单文件，排除 95% 以上独立文件；
  - **Step 2 (头部指纹校验)**：读取前 8KB 快速校验快照指纹，高效排除偶然同大小文件；
  - **Step 3 (全量 MD5 确认)**：流式读入计算完整哈希，100% 确认重复，0 误判。
- 🗂️ **全类型与分栏筛选**：
  - 支持全部、图片、视频、音频、文档、安装包与压缩包。
- 🏷️ **智能区分原件与副本**：
  - 按真实修改时间自动将最早产生的文件标记为 `[原文件]`，其余标记为 `[副本]`。
- 🎯 **智能一键操作**：
  - 提供【保留最早 (推荐)】、【保留最新】、【全选副本】、【全不选】；
  - 底部实时统计已选副本与预计释放空间，安全删除并自动刷新系统存储。

### 4. 高级音视频播放器 (内置自由拖拽与沉浸全屏)
- 🎚️ **进度条自由拖拽 (Seekbar)**：
  - 无论窗口模式还是全屏模式，均支持手动拖动进度条跳转播放，实时显示拖动时间，松手精准跳转。
- 🖥️ **彻底沉浸全屏与无黑边铺满**：
  - 突破系统 Dialog 窗口与边距限制，穿透适配中置挖孔/刘海屏区域；
  - 支持双击视频或点击按钮切换【铺满全屏（消灭黑边）】与【适应屏幕（完整比例）】。
- 🔄 **横竖屏自由旋转**：
  - 全屏控制栏支持一键翻转横屏/竖屏，配合手机传感器随心旋转。

---

### 5. 智能分类文件管理
- **全格式支持**：
  - 📷 **图片**：JPG, PNG, WEBP, GIF, SVG, RAW, HEIC 缩略图极速加载。
  - 🎵 **音乐**：MP3, FLAC, WAV, AAC, OGG, M4A, APE 等高质量音频检索与信息提取。
  - 📄 **文档**：PDF, DOC/DOCX, XLS/XLSX, PPT/PPTX, TXT, EPUB, Markdown。
  - 🎬 **视频**：MP4, MKV, AVI, MOV, FLV, TS 等全格式探测。
  - 📦 **安装包 (APK)**：深度解析未安装 APK 文件，直接提取真实应用名、高清应用图标、包名及版本号 (VersionName / VersionCode)，支持一键调用系统安装器。
  - 🗜️ **压缩包 (ZIP/RAR/7Z)**：集成 Zip4j，支持包内文件目录树浏览与一键免解压预览/解压到本地。
- **批量与全选操作**：支持任意分类下的多选、全选、批量删除、系统分享，以及一键带入 LocalSend 快传发给电脑。
- **物理文件属性排序**：时间、大小、名称多维度排序，严格按文件真实属性计算。

### 6. 开源 LocalSend 协议局域网互传
原生兼容开源 [LocalSend 协议 (Protocol v2)](https://github.com/localsend/localsend)，可直接与局域网内的 Windows、macOS、Linux、iOS 以及 Android 官方 LocalSend 客户端无缝互传：
- 📡 **UDP 组播自动发现 (Multicast Discovery)**：
  - 监听与广播组播地址 `224.0.0.167:53317`，秒级雷达探测周围设备。
- 🚀 **NanoHTTPD 内置高速传输服务**：
  - 接收文件自动流式写入 `Download/LocalSend/`，防重名自增处理。
- 📤 **流式多文件并发推送客户端**：
  - 采用 OkHttp 流式推送，实时计算传输百分比与即时传输速率（MB/s），前台常驻服务保证息屏不中断。

---

### 7. SMB 局域网网络共享 (SMB1 / SMB2 / SMB3)
内置 **CodeLibs JCIFS** 协议引擎，支持直连 Windows、macOS、Linux Samba、OpenWrt 及 NAS（群晖/威联通/飞牛等）共享文件夹：
- 🔍 **局域网双模探测**：同时结合 **445 端口并发扫描**与 **mDNS (`_smb._tcp.`)** 服务发现，自动列出局域网可连接设备。
- 🔐 **全版本协议与凭证支持**：支持 `SMB1 ~ SMB3.1.1` 加密协商、账号密码 / 域控 / 匿名访客登录，支持测试连接、保存主机及手动直连共享目录。
- ⏯️ **双向断点续传与后台保活**：上传与下载均基于 `.smbpart` 临时文件与 `SmbRandomAccess` 字节偏移精确定位，支持暂停/恢复、断网自动保留进度与重启后继续传输，并配备前台保活服务。
- 🎬 **本地 HTTP Range 代理在线看片**：通过内置 NanoHTTPD Range 流媒体代理，无需等待下载即可直接流式播放远程视频与音乐，支持进度条拖拽与全屏铺满；支持多图连续在线预览与文档缓存打开。
- 📂 **全套远程文件操作**：支持远程目录面包屑导航、搜索与分类筛选、排序、新建文件夹、重命名、复制/剪切/粘贴、递归删除，以及多文件双向高速上传与下载（本地保存至 `Download/SMB/`）。

## 🛠️ 项目工程技术栈

| 模块 | 技术选型 | 说明 |
|---|---|---|
| UI 框架 | Jetpack Compose + Material 3 | 现代化声明式响应式界面 |
| 清理引擎 | StorageCleanerEngine (System Junk & App Manager) | 全盘深度扫描、图库缩略图、多格式过滤与 App 存储分析 |
| 视频处理 | FFmpeg-Kit (Mobile-FFmpeg) | 本地多线程解封装与秒级无损合并 |
| 局域网传输 | LocalSend Protocol v2 (OkHttp + NanoHTTPD) | 开源跨平台无损局域网快传 |
| 网络共享 | CodeLibs JCIFS (SMB1/2/3) + NanoHTTPD Range Proxy | 局域网 SMB 文件管理与音视频流式播放 |
| 去重引擎 | MessageDigest (MD5 Streaming) + Multi-stage filter | 三阶段流式比对防 OOM |
| 压缩解压 | Zip4j | 跨平台 ZIP/RAR 目录树与解压 |
| 架构设计 | MVVM + StateFlow + Coroutines | 异步非阻塞响应式架构 |
